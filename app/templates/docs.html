最短示例

先自检，再发起正式请求

先确认鉴权和模型可见性，再按业务选择 Responses、Chat Completions 或原生入口。

自检

获取模型列表

用于确认 API Key、访问地址和可用模型。

curl {{ external_v1_base_url }}/models \
  -H "Authorization: Bearer YOUR_PLATFORM_API_KEY"
推荐

Responses 文本请求

OpenAI 兼容新接入优先使用该入口。

curl {{ external_v1_base_url }}/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_PLATFORM_API_KEY" \
  -d '{
    "model": "YOUR_MODEL",
    "input": "用一句话介绍这个服务"
  }'
兼容

Chat Completions 请求

用于仍依赖 Chat Completions 协议的客户端。

curl {{ external_v1_base_url }}/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_PLATFORM_API_KEY" \
  -d '{
    "model": "YOUR_MODEL",
    "messages": [
      {"role": "user", "content": "用一句话介绍这个服务"}
    ]
  }'
Gemini

generateContent 原生请求

用于 Gemini SDK 或按 Gemini 原生协议接入的客户端。

curl {{ external_base_url }}/v1beta/models/YOUR_GEMINI_MODEL:generateContent \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_PLATFORM_API_KEY" \
  -d '{
    "contents": [
      {"role": "user", "parts": [{"text": "用一句话介绍这个服务"}]}
    ]
  }'
Claude

Messages 原生请求

用于 Claude SDK 或按 Claude Messages API 接入的客户端。

curl {{ external_base_url }}/v1/messages \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_PLATFORM_API_KEY" \
  -d '{
    "model": "YOUR_CLAUDE_MODEL",
    "max_tokens": 256,
    "messages": [
      {"role": "user", "content": "用一句话介绍这个服务"}
    ]
  }'

开发环境

环境变量

服务端脚本、CLI 和 SDK 可优先用环境变量。

OPENAI_API_KEY=YOUR_PLATFORM_API_KEY
OPENAI_BASE_URL={{ external_v1_base_url }}
注意

模型与能力

模型名、视觉、工具调用、图片生成等能力以平台授权和实际路由结果为准。

外部请求统一由平台按可用性优先策略选择可用提供商。业务侧不要传内部提供商名称、后台调试参数或非标准路由字段。

错误格式

失败时保留错误码和 trace_id

对外错误采用 OpenAI 兼容的 error 对象，便于定位鉴权、余额、模型、容量或上游问题。

JSON

普通错误响应

接入方排障时优先记录这些字段。

{
  "error": {
    "message": "具体错误说明",
    "type": "server_error",
    "code": "upstream_request_failed",
    "trace_id": "请求追踪 ID",
    "retryable": true,
    "recoverable": true,
    "category": "upstream"
  }
}
SSE

流式错误事件

流式连接建立后出错，会尽量发送 error 事件并以 DONE 收尾。

event: error
data: {"error":{"message":"具体错误说明","code":"stream_interrupted"}}

data: [DONE]
